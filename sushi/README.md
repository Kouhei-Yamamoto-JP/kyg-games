# 回転寿司ゲーム（プロトタイプ）

ベルトコンベアを流れる寿司をお客さんの注文に合わせてタッチ／クリックして届ける、シンプルなブラウザゲームです。

## 遊び方

1. スタート画面で **スタート** を押す
2. 中央のベルトにお皿が流れる
3. 上のお客さんの注文（絵文字）と同じ寿司のお皿をタップ／クリック
4. 正解でスコア加算、コンボでボーナス
5. まちがい or 我慢切れでライフ減少（❤️×3）
6. ライフが 0 でゲームオーバー

お客さんは時間とともに最大 5 人まで増えていきます。

## 起動方法

ビルド不要です。どちらかで開けます。

### ローカルサーバー（推奨）

```bash
cd /workspace/kaiten-sushi
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開く。

### ファイル直接

`index.html` をブラウザで開いても動作します（クライアント完結）。

## 操作

| 操作 | 内容 |
|------|------|
| タップ／クリック | お皿を選択して配膳 |
| スタート／もう一度 | ゲーム開始・再挑戦 |

スマホ・タブレット・PC 対応（レスポンシブ、タッチ＆マウス）。

## ファイル構成

```
kaiten-sushi/
  index.html   … 画面構成
  style.css    … 見た目・レスポンシブ
  game.js      … ゲームロジック
  README.md    … このファイル
```

## 既知の制限・今後のアイデア

- v1 のため、効果音・BGM なし
- お皿の軌道は楕円近似（実店舗の角丸長方形ベルトより単純）
- 寿司の見た目は絵文字中心（SVG 差し替え可）
- ハイスコア保存・難易度選択なし
- オンライン対戦・ランキングなし

**次に足すと楽しいもの:** 効果音、コンボ演出強化、レア寿司、特殊お客さん、ローカルストレージのハイスコア、難易度（かんたん／むずかしい）。
