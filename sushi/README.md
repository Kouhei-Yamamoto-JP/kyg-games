# 回転寿司ゲーム（クラフト版）

材料を選んで寿司を作り、レーンの空き皿に乗せるブラウザゲームです。注文と合うお皿がお客さんの座席前を通ると、お客さんが自動で取ります。レベルが上がると使えるネタが増えます。

## 遊び方

1. スタート画面で **スタート** を押す
2. 下のクラフトパネルで材料を正しい順にタップして寿司を作る
3. **レーンに出す** で空き皿に乗せる
4. レーン上の寿司が、同じ注文のお客さんの前（座席）を通ると **自動配膳**（スコア加算・コンボ）
5. 我慢切れでライフ減少（❤️×5）。合わない寿司はレーンを回り続ける
6. 成功配膳を重ねるとレベルアップ → 新ネタ解放
7. ライフが 0 でゲームオーバー

お客さんは時間とともに最大 5 人まで増えていきます。

### レシピ

| 種類 | 手順 | ネタ例 |
|------|------|--------|
| **にぎり** | シャリ → ネタ | まぐろ・サーモン・えび・たまご |
| **軍艦** | シャリ → 海苔 → ネタ | いくら・うに |
| **巻物** | 海苔 → シャリ → ネタ | かっぱ巻（きゅうり）・鉄火巻（まぐろ） |

材料の順番を間違えてもライフは減りません（クラフトがリセットされるだけ）。

### レベルとネタ解放

成功配膳 **6 回ごと** にレベルが上がります。クラフトパネルとお客さんの注文は、現在レベルで解放済みのネタだけです。

| レベル | 解放内容 |
|--------|----------|
| **Lv1** | まぐろ・サーモン（にぎりのみ） |
| **Lv2** | ＋えび・たまご |
| **Lv3** | ＋いくら・うに（軍艦レシピ解放） |
| **Lv4** | ＋かっぱ巻・鉄火巻（巻物解放） |
| **Lv5+** | 新ネタなし。お客さんの我慢時間がやや短く・レーンが少し速く |

解放時はトースト「新ネタ解放！〇〇」を表示します。

## 起動方法

ビルド不要です。

### ローカルサーバー（推奨）

```bash
cd /workspace/kyg-games/sushi
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開く。

### ファイル直接

`index.html` をブラウザで開いても動作します（クライアント完結）。

## 操作

| 操作 | 内容 |
|------|------|
| 材料ボタン | クラフトの次のステップに使う（解放済みのみ表示） |
| レーンに出す | 完成寿司を空き皿へ |
| （お皿） | タップ不要。座席前で自動配膳 |
| スタート／もう一度 | ゲーム開始・再挑戦 |

スマホ・タブレット・PC 対応（レスポンシブ、タッチ＆マウス）。

```
sushi/

```

## ビジュアル

寿司・ネタは絵文字ではなく **CSS アイコン**（にぎり／軍艦／巻物の形＋色）で表示します。材料ボタン・クラフトプレビュー・レーンのお皿・お客さん注文で共通です。日本語ラベルも併記します。

## 既知の制限・今後のアイデア

- 効果音・BGM なし
- お皿の軌道は楕円近似（自動配膳は座席 progress との距離判定）
- 寿司の見た目は絵文字中心
- ハイスコア保存・難易度選択なし

**次に足すと楽しいもの:** 効果音、コンボ演出強化、レア寿司、ローカルストレージのハイスコア。
