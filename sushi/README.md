# 回転寿司ゲーム（クラフト版）

材料を選んで寿司を作り、レーンの空き皿に乗せ、お客さんの注文に合わせて配膳するブラウザゲームです。

## 遊び方

1. スタート画面で **スタート** を押す
2. 下のクラフトパネルで材料を正しい順にタップして寿司を作る
3. **レーンに出す** で空き皿に乗せる
4. 上のお客さんの注文と同じ寿司のお皿をタップ／クリックして配膳
5. 正解でスコア加算、コンボでボーナス
6. まちがい配膳 or 我慢切れでライフ減少（❤️×3）
7. ライフが 0 でゲームオーバー

お客さんは時間とともに最大 5 人まで増えていきます。

### レシピ

| 種類 | 手順 | ネタ例 |
|------|------|--------|
| **にぎり** | シャリ → ネタ | まぐろ・サーモン・えび・たまご |
| **軍艦** | シャリ → 海苔 → ネタ | いくら・うに |
| **巻物** | 海苔 → シャリ → ネタ | かっぱ巻（きゅうり）・鉄火巻（まぐろ） |

材料の順番を間違えてもライフは減りません（クラフトがリセットされるだけ）。

## 起動方法

ビルド不要です。

### ローカルサーバー（推奨）

```bash
cd /workspace/kyg-games/sushi
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開く。

### ファイル直接

`index.html` をブラウザで開いても動作します（クライアント完結）。

## 操作

| 操作 | 内容 |
|------|------|
| 材料ボタン | クラフトの次のステップに使う |
| レーンに出す | 完成寿司を空き皿へ |
| お皿タップ | 注文と一致すれば配膳 |
| スタート／もう一度 | ゲーム開始・再挑戦 |

スマホ・タブレット・PC 対応（レスポンシブ、タッチ＆マウス）。

## 既知の制限・今後のアイデア

- 効果音・BGM なし
- お皿の軌道は楕円近似
- 寿司の見た目は絵文字中心
- ハイスコア保存・難易度選択なし

**次に足すと楽しいもの:** 効果音、コンボ演出強化、レア寿司、ローカルストレージのハイスコア。
