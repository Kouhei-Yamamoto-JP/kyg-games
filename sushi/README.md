# 回転寿司ゲーム（クラフト版）

材料を選んで寿司を作ると、完成後に自動でレーンの空き皿に乗ります。注文と合うお皿がお客さんの座席前を通ると自動配膳。制限時間内にスコアを稼ごう。レベルが上がると使えるネタが増えます。

## 遊び方

1. スタート画面で **スタート** を押す
2. 下のクラフトパネルで材料を正しい順にタップして寿司を作る
3. **完成すると自動でレーンに乗る**（空き皿がなければ待つ）
4. レーン上の寿司が、同じ注文のお客さんの前を通ると **自動配膳**（スコア加算・コンボ・**+10秒**）
5. 制限時間は最初 **60秒**。提供成功で伸びるが、セッション合計は最大 **600秒**
6. 我慢切れでライフ減少（❤️×5）。合わない寿司はレーンを回り続ける
7. 成功配膳を重ねるとレベルアップ → 新ネタ解放
8. 残り時間 0 またはライフ 0 で終了（時間切れは「クリア！」）

ランキングは **この端末の localStorage**（`kyg-sushi-ranking-v1`）に保存。API 差し替え用に `RankingAPI.fetchRanking` / `RankingAPI.saveScore` に集約。

### レシピ

| 種類 | 手順 | ネタ例 |
|------|------|--------|
| **にぎり** | シャリ → ネタ | まぐろ・サーモン・えび・たまご・はまち・ほたて |
| **軍艦** | シャリ → 海苔 → ネタ | いくら・うに・コーン・ねぎとろ |
| **巻物** | 海苔 → シャリ → ネタ | かっぱ巻・鉄火巻・納豆巻 |

材料の順番を間違えてもライフは減りません（クラフトがリセットされるだけ）。画像がないネタは CSS / 絵文字フォールバック表示。

### レベルとネタ解放

成功配膳 **6 回ごと** にレベルが上がります。

| レベル | 解放内容 |
|--------|----------|
| **Lv1** | まぐろ・サーモン（にぎりのみ） |
| **Lv2** | ＋えび・たまご |
| **Lv3** | ＋いくら・うに（軍艦レシピ解放） |
| **Lv4** | ＋かっぱ巻・鉄火巻（巻物解放） |
| **Lv5** | ＋はまち・ほたて |
| **Lv6** | ＋コーン軍艦・ねぎとろ軍艦 |
| **Lv7** | ＋納豆巻 |
| **Lv8+** | 新ネタなし。お客さんの我慢時間がやや短く・レーンが少し速く |

解放時はトースト「新ネタ解放！〇〇」を表示します。お客さんの我慢時間は約 30秒〜最低 10秒で徐々に短くなります。

## 起動方法

ビルド不要です。

### ローカルサーバー（推奨）

```bash
cd /workspace/kyg-games/sushi
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開く。

### ファイル直接

`index.html` をブラウザで開いても動作します（クライアント完結）。

## 操作

| 操作 | 内容 |
|------|------|
| 材料ボタン | クラフトの次のステップに使う（解放済みのみ表示） |
| （完成時） | 自動で空き皿へ。空きがなければトーストして待機 |
| （お皿） | タップ不要。座席前で自動配膳 |
| スタート／もう一度 | ゲーム開始・再挑戦 |
| ランキング | この端末のスコア一覧 |

スマホ・タブレット・PC 対応（レスポンシブ、タッチ＆マウス）。

## ファイル構成

```
sushi/
  index.html   … 画面構成（クラフトパネル含む）
  style.css    … 見た目・レスポンシブ（CSS 寿司アイコン含む）
  game.js      … ゲームロジック（RankingAPI 含む）
  README.md    … このファイル
```

## ビジュアル

寿司・材料アイコンは `assets/icons/` の PNG（透過）。無いネタは CSS アイコン / 絵文字フォールバック。
